# 버림받은 왕조 — 사운드 계획

## 0. 지금 게임에 들어가 있는 것

음원 파일 없이 브라우저에서 바로 만든 소리가 이미 들어가 있다. 파일을 넣으면 그 파일이 이 소리 대신 재생된다.

| 구분 | 지금 들어간 소리 |
|---|---|
| 카드 끌기 | 끈 거리 22px마다 짧은 종이 긁는 소리 한 알갱이. 세게 끌수록 조금씩 커진다 |
| 카드 날아감 | 바람이 스치는 소리 |
| 버튼 | 작은 나무 딸깍 |
| 결투 | 베기(쉭+둔탁), 막기(쇳소리 울림), 피격(낮은 둔탁), 격파(화음), 패배(내려가는 저음) |
| 알림 | 갈림길 종, 위기 경고 저음, 결말 종 |
| 음악 | 제목·결말·외전 화면에서 어머니의 자장가를 오르골처럼 연주한다. 막별 배경음은 파일이 들어오기 전까지 조용하다 |
| 설정 | 효과음 켬/끔, 음악 켬/끔. 제목 화면에도 소리 켜기/끄기 버튼이 있다 |

브라우저 정책 때문에 첫 터치 전에는 소리가 나지 않는다. 그래서 제목 화면의 첫 터치에서 소리를 깨운다.

## 1. 음악의 방향

**모든 곡은 하나의 멜로디에서 나온다.** 어머니의 자장가 "별이 이름을 적으면, 양치기도 왕"이 이 게임의 소리 정체성이다.

- 1막에서는 어머니가 흥얼거리던 모습 그대로, 단순하고 가깝게 들린다.
- 막이 진행될수록 같은 선율이 다른 악기와 박자로 변주된다.
- 결말에 이르러서야 끝 소절("양치기는 이름을 안 적어도 양을 안다")이 완성된다.

이렇게 하면 플레이어는 정체를 몰라도 귀로 복선을 듣게 된다. 윤회를 거듭할수록 같은 멜로디가 다르게 들리는 경험도 만들 수 있다.

**악기 팔레트**

- 기본: 오르골, 류트나 클래식 기타, 첼로, 나무 피리, 낮은 허밍
- 왕도·권력: 하프시코드, 금관, 종
- 북부·첨탑: 바람 소리 드론, 글래스 하모니카, 낮은 합창
- 쓰지 않을 것: 신스 리드, 강한 EDM 비트. 양피지와 촛불의 세계에서 튀기 때문이다.

### 2-1. 메인과 진행 음악

| `act2` | 2막 「외양간 다락」 | 2막 은신 | 류트, 나무 피리, 장작 소리가 어울리는 따뜻한 3박자. 숨 돌리는 곡 | 2~3분 루프 |

## 3. 효과음 목록

현재 합성음은 임시용이다. 녹음 음원으로 바꾸면 체감이 크게 달라진다. 우선순위 순서로 적었다.

| 우선 | 키 (SOUND_FILES) | 소리 | 녹음·제작 팁 |
|---|---|---|---|
| 1 | `slide` | 카드 끌 때 "사각" 한 알갱이 | 두꺼운 수제 종이나 양피지를 손끝으로 2~4cm 쓴다. 콘덴서 마이크를 10cm 이내로 가깝게 둔다. 30~60ms짜리 알갱이 5~8개를 만들어 무작위로 돌린다(지금은 한 파일만 연결된다. 여러 개를 쓰려면 코드에 배열을 추가해야 한다) |
| 1 | `fly` | 카드가 날아가는 소리 | 종이 한 장을 빠르게 휘두르는 바람 소리 0.2초 |
| 1 | `page` | 결과 장 넘기기 | 두꺼운 책장 넘기기 |
| 2 | `tap` | 버튼 | 나무 단추를 손톱으로 톡 |
| 2 | `slash` / `parry` / `hurt` | 베기 / 막기 / 피격 | 칼집에서 칼 빼는 소리, 쇠 두 개 부딪히는 울림, 모래주머니 둔탁 |
| 2 | `win` / `lose` | 격파 / 패배 | 짧은 금관 화음 / 낮은 현 하강 |
| 3 | `chime` | 갈림길 | 작은 종 한 번 |
| 3 | `crisis` | 위기 | 낮은 북 롤과 현 트레몰로 |
| 3 | `ending` | 결말 | 큰 종 하나가 멀리서 |

**장면 효과음 (다음 단계, 코드 추가 필요)**
카드의 장면(`who`) 기준으로 배경 앰비언스를 깔면 몰입이 크게 오른다.

- 불탄 별궁·불탄 마을: 타닥거리는 불
- 나루터·강: 물결
- 장대비: 빗소리
- 주막·장터: 웅성거림, 잔 부딪는 소리
- 첨탑: 바람, 쇠사슬
- 왕도 성문: 군중, 종탑

## 4. 기술 사양

- **형식:** 아이폰 사파리까지 생각하면 `.m4a`(AAC)나 `.mp3`가 안전하다.
- **음량 기준:** 배경음은 대략 -16 LUFS, 효과음은 피크 -6dBFS 안쪽. 게임 안 기본 음량은 배경음 0.5다.
- **루프:** 배경음은 앞뒤가 이어지게 자른다. 끝에서 튀는 소리가 나지 않게 0.1초 페이드를 준다.
- **용량:** 배경음 한 곡당 2~3MB, 효과음은 개당 50KB 안쪽이 목표.
- **연결 방법:** `assets/` 폴더에 넣고 코드의 `SOUND_FILES` / `BGM_FILES`에 경로를 적는다.

```js
SOUND_FILES.slide = "sfx/slide.m4a";
BGM_FILES.title  = "bgm/main_theme.m4a";
```

- **배포 주의:** 지금 claude.ai 아티팩트는 HTML 파일 하나만 올린다. 음원을 쓰려면 Netlify처럼 폴더째 올리는 곳에 배포하거나, 아티팩트의 자산 저장소(assets 기능)에 올리는 작업이 따로 필요하다.

|---|---|---|

## 6. 만드는 방법

| 방법 | 장점 | 주의 |
|---|---|---|
| 직접 작곡 | 자장가 모티프를 일관되게 관리하기 쉽다 | 시간이 든다 |
| 작곡가 외주 | 품질과 일관성 | 비용은 작업 범위와 사람마다 달라서 여기서는 말할 수 없다. 이 문서를 그대로 의뢰서로 쓸 수 있다 |
| 무료·로열티 프리 라이브러리 | 빠르다 | 곡마다 라이선스(상업 이용, 출처 표기) 확인 필수. 모티프 통일이 어렵다 |
| AI 음악 생성 도구 | 빠른 시안 | 서비스마다 상업 이용 조건이 다르다. 출시 전에 약관 확인 필수 |

효과음은 휴대폰 녹음으로도 시안을 충분히 만들 수 있다. 종이 슬라이드는 직접 녹음하는 걸 추천한다. 게임의 손맛을 정하는 소리라서다.
