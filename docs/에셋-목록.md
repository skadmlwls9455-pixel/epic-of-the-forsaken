# 버려진 자의 서사시 — 그림 에셋 목록

이미지 생성 AI로 뽑아서 다듬을 때 쓰는 목록입니다. 프롬프트 최적화는 맡기고, 여기서는 **무엇이 어디에 어떻게 쓰이는지**와 **무엇이 그려져야 하는지**만 적습니다.

---

## 0. 공통 미술 방향 (모든 프롬프트 앞에 붙일 것)

**한 줄 요약:** 촛불 아래 양피지에 잉크와 인주로 그린, 낡은 왕실 기록물 같은 그림.

| 항목 | 기준 |
|---|---|
| 기법 | 목판화·동판화 느낌의 잉크 선, 거친 해칭(빗금 음영), 종이 결이 보이는 질감. 매끈한 3D·디지털 페인팅 금지 |
| 색 | 거의 흑백(먹색·짙은 갈색) + 포인트 색 두 가지만: **금빛 황토(#c8a04a 근처)**, **인주 붉은색(#b91c1c 근처)** |
| 배경 톤 | 게임 화면은 아주 어두운 갈색(#0e0c0a). 그 위에 올라가므로 어두운 배경과 잘 어울려야 함 |
| 상징 | **별 일곱 개**(왕가·별지기의 인장), 양치기 지팡이, 원장(두꺼운 장부), 반지, 촛불, 갈대 |
| 시대감 | 중세 후기 가상 왕국. 동양·서양 어느 한쪽으로 치우치지 않은 무국적 판타지. 화려한 갑옷·마법 효과 금지, 생활감 있는 소박한 물건 |
| 피할 것 | 네온 빛, 렌즈 플레어, 과한 광택, 웃는 얼굴의 귀여운 화풍, 글자(이미지 안에 글자 넣지 않기), 워터마크 |

**일관성을 지키는 요령**
- 같은 묶음(아이콘 16개, 인물 문장 16개)은 **한 번에 같이** 뽑거나, 처음 마음에 든 한 장을 기준 이미지로 계속 붙여서 뽑는 게 좋습니다.
- 생성 후에는 **배경 제거(투명 PNG) → 크기 맞추기 → 색 두 가지로 보정** 세 단계를 거치면 AI티가 많이 줄어듭니다.

## 4. 인물 — 코드의 `PORTRAIT`

카드 왼쪽 위 동그라미(40px)에 들어갑니다. 너무 작아서 얼굴 초상보다 **인물마다 다른 '문장(도장)'**이 훨씬 잘 보이고 세계관에도 맞습니다. 둘 중 하나로 통일하세요.

**공통 규격:** 정사각 320×320, 투명 PNG, 원 안에 꽉 차는 구도.
- 문장안: 붉은 인주로 찍은 둥근 도장 느낌, 가운데에 상징물 하나.
- 초상안: 어깨 위 흉상, 목판화 선, 정면 또는 3/4.

| 막기 방패 | 막았을 때 화면 아래 한쪽에 찍히는 방패 | 512×560 투명 PNG | 정면에서 본 방패, 금빛 테두리, 가운데 십자 또는 별. 약간 기울어진 각도 |
| 갈림길 도장 | 선택지의 '갈림길' 표시 | 200×80 투명 PNG | 붉은 인주로 찍은 네모 도장, 글자 없는 테두리만(글자는 코드가 넣음) |
| 결말 인장 | 결말 앨범의 본 결말 표시 | 256×256 투명 PNG | 붉은 밀랍 봉인, 가운데 별 일곱 |

## 9. 넣는 방법

1. 그림 파일을 `assets/` 폴더에 넣습니다.
2. `bastard-v5.html`에서 해당 칸에 파일 이름을 적습니다.

```js
UI_ART.titleBg = "title_bg.jpg";
ART.herb.img   = "item_herb.png";
PORTRAIT["리엔"] = "crest_lien.png";
END_ART.lien_wall = { img: "end_lien_wall.png" };
```

3. 그림이 없거나 못 불러오면 지금의 선 아이콘·첫 글자가 대신 나와서 화면이 깨지지 않습니다.

**배포 주의:** claude.ai 아티팩트는 HTML 한 장만 올라가므로, 그림을 넣은 버전은 Netlify처럼 폴더째 올리는 곳에서 확인해야 합니다.
