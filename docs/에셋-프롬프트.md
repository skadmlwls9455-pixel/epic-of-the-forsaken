# 버려진 자의 서사시 — 이미지 생성 요청서

이미지 생성 AI에 그대로 넣을 수 있게 정리한 요청서입니다.
에셋 하나마다 **파일 이름 · 크기 · 쓰이는 곳 · 프롬프트**를 적었습니다. 프롬프트 다듬기는 GPT에 맡기셔도 되도록, 무엇을 그려야 하는지 빠짐없이 적는 데 집중했습니다.

- 용도와 화면 위치 설명은 `docs/에셋-목록.md`에 따로 있습니다.
- 완성된 파일은 `assets/` 폴더에 아래 **파일 이름 그대로** 넣으면 코드에 바로 연결할 수 있게 맞춰 두었습니다.

---

## 0. 모든 요청에 공통으로 붙일 문장

### 0-1. 화풍 (STYLE) — 매 프롬프트 맨 앞에 붙이기

```
Hand-printed woodcut and copperplate engraving style, dense ink hatching, visible paper fibre texture, aged parchment feel. Nearly monochrome: deep sepia-black ink, with only two accent colours used sparingly — muted gold ochre (#C8A04A) and vermilion seal-ink red (#B91C1C). Low-fantasy late-medieval kingdom, humble everyday objects, candlelit mood. Flat print look, no 3D render, no glossy digital painting.
```

### 0-2. 금지 (NEGATIVE) — 지원되면 네거티브 프롬프트에, 아니면 끝에 "Avoid:"로 붙이기

```
text, letters, words, calligraphy, watermark, signature, logo, frame border (unless asked), neon, lens flare, bloom, glossy metal, plastic look, cute chibi style, anime style, modern objects, photorealism, 3D render, bright saturated colours, blue or purple colour cast
```

### 0-3. 투명 배경이 필요한 에셋에 붙일 문장

```
Single isolated object centred on a plain flat background (pure #FFFFFF), generous empty margin around it, no ground shadow, no scenery — so the background can be removed cleanly.
```

> 대부분의 생성 AI는 진짜 투명 PNG를 못 만듭니다. 흰 배경으로 뽑은 뒤 배경 제거 도구(remove.bg, 포토샵 등)로 지우세요.

### 0-4. 일관성 요령

1. 같은 묶음(아이콘 16개, 인물 16명)은 **첫 장을 마음에 들 때까지 뽑고**, 그 이미지를 참고 이미지로 붙여서 나머지를 같은 화풍으로 요청합니다.
2. 가능하면 묶음 전체를 **한 장의 시트(격자)로 먼저 뽑은 뒤 잘라 쓰는 것**이 화풍이 가장 잘 맞습니다. 시트용 프롬프트를 각 묶음 첫머리에 넣어 두었습니다.
3. 뽑은 뒤에는 **두 가지 색(금빛 황토·인주 빨강) 외의 색은 채도를 낮춰** 맞추면 AI티가 크게 줄어듭니다.
