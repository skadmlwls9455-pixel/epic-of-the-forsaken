# TRPG 백업

빌드 없이 파일만 올리면 되는 정적 사이트. Netlify, 나루 등 어디든 폴더째 올리면 돼.

## 구조

```
index.html          목록 페이지 (검색, 룰/태그 필터, 캐릭터 아바타)
data/scenarios.js   목록 데이터. 로그 추가할 때 여기만 수정
logs/*.html         로그 페이지 한 개당 파일 하나
css/site.css        목록 스타일
css/log.css         로그 스타일 (소설형 본문, 프로필 카드, 롤20 마크업 대응)
js/                 목록/로그 페이지 스크립트
tools/new-log.html  로그 페이지 + 목록 항목 생성 도구
room/               TRPG ROOM (CoC 세션 플레이어). 자세한 건 room/README.md
```

## 로그 추가하는 법

1. `tools/new-log.html`을 브라우저로 열기
2. 제목, 룰, GM 등을 입력하고 등장인물을 한 줄에 한 명씩 적기
   `이름 | 역할 | 이미지 주소 | 한 줄 설명` (뒤쪽은 비워도 됨)
3. 채팅 내역을 붙여넣고 만들기 (미리보기로 확인 가능)
4. 받은 html 파일을 `logs/`에 넣기
5. 표시된 항목을 `data/scenarios.js` 배열 맨 위에 붙여넣기
6. 사이트에 다시 올리기

## 붙여넣을 수 있는 형식

| 형식 | 예시 |
| --- | --- |
| 일반 텍스트 | `한서진: 문에 귀를 대 볼게요.` 한 줄씩 |
| 나레이션 | `> 복도에는 비 냄새가 가득하다.` 또는 `*문장*` |
| 장면 전환 | `---` |
| 카카오톡 내보내기 | `2025. 4. 10. 오후 3:21, 이름 : 내용` |
| 디스코드 복사 | `이름 — 오늘 오후 3:21` 아래에 내용 |
| 롤20 | 챗 아카이브에서 F12 → `div.content` 우클릭 → Copy → Copy outerHTML |

화자 없는 줄은 바로 앞 대사에 이어 붙어. 이름은 등장인물에 적은 이름과 똑같아야 프로필과 연결돼.

## 손으로 고치는 법
`logs/sample.html`을 보면 돼. 하단 `<script id="meta">`의 JSON이 제목, 등장인물 정보고, 본문은 `.msg` 블록이야.

## 참고
- 이미지는 외부 주소를 그대로 쓰면 원본 서비스가 사라질 때 같이 깨져. 백업이 목적이면 이미지도 이 폴더(예: `images/`)에 내려받아 상대 경로로 바꿔두는 게 안전해.
- 모든 페이지에 `noindex`가 들어 있어서 검색엔진에 안 잡혀. 공개할 거면 지워.
- 이 사이트에는 로그인 기능이 없어. 편집은 파일을 직접 고쳐서 다시 올리는 방식이라, 올리는 계정(Netlify 등)을 가진 사람만 바꿀 수 있어.
