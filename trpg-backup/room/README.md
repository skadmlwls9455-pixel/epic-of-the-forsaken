# TRPG ROOM — CoC Session Player

`trpg-backup/room/`에 있어. 사이트 주소 뒤에 `/room/`을 붙이면 열려.

CoC 7판 세션을 브라우저 하나로 진행하는 비주얼노벨형 룸. 빌드 없이 정적 파일만 올리면 돼 (Netlify 등 폴더째 업로드).
`index.html`을 바로 열어도 동작해.

## 지금 들어 있는 것 (Phase 1 + 일부 Phase 2)

- 타이틀 화면 (START / CONTINUE / LOAD)
- 풀스크린 장면: 배경, 장면 전환 7종, 효과 레이어(비/눈/먼지/꽃잎/안개/그레인/비네트/깜박임/글리치), 스탠딩(이니셜 대체) + 표정, 타이핑 대사창
- CoC 7판 판정: 보통/어려움/극단적, 보너스/페널티 주사위(십의 자리 후보 표시), 대성공/대실패 규칙(기능치 50 기준), 행운 소비, 강행 판정(+KP가 적어둔 실패 결과), 비밀 판정
- 주사위 패널: D3~D100, `2d6+3`, `1d4+db`(캐릭터 DB 자동 적용), 채팅창에 `/r 2d6+3`
- SAN 판정: 성공/실패 손실식, 대실패는 최대 손실, 일시적/부정기/영구 광기 경고(KP 시점에서만 표시)
- 캐릭터 시트: 능력치, HP/MP/SAN/LUCK, 파생치(DB, 체격, MOV), 기능치 편집·추가, 상태 이상, 소지품
- 단서 보드(미획득은 `???`), 핸드아웃, 조사 모드(이미지 위 클릭 영역 + 기능치 판정 + 단서/SAN 연동)
- 세션 로그: ALL / RP / DICE / SYSTEM / CLUE / OOC 필터, 텍스트 내보내기
- KP 시점: 장면 전환, 효과 토글, 핸드아웃 공개, 단서 공개, 표정, 비밀 판정, 상태 조정, 효과음
- 저장: 자동 저장 + 슬롯 3개 + JSON 내보내기/불러오기, 세션 종료 요약
- 테마 3종 (여름 / 고딕 / VHS)
- 편집 모드: 상단 `편집 모드`를 켜면 배경/스탠딩/프로필/핸드아웃 슬롯이 점선으로 표시돼. 눌러서 교체, 끌어놓기, Ctrl+V 붙여넣기 가능. `에셋 관리`에서 전체 슬롯을 한 번에 채울 수 있고, 타이틀 화면의 `IMAGES` 버튼으로도 열려

## 아직 없는 것

멀티플레이(실시간 동기화, 플레이어별 비밀 메시지), AI KP, 전투 턴 관리, 시나리오 에디터, 단서 연결선 그래프.
PC/KP 시점 전환은 한 화면에서 쓰는 용도라 보안 기능이 아니야 (개발자 도구로 비밀 로그를 볼 수 있어). 진짜 비밀 처리는 서버가 붙는 Phase 4에서 해야 해.

## 구조

```
index.html
css/room.css        레이아웃, 테마(변수), 효과, 전환
js/coc.js           룰 엔진 (DOM 의존 없음, node 테스트 가능)
js/store.js         상태, 저장/불러오기, 통계
js/fx.js            효과 레이어, 장면 전환, BGM
js/assets.js        편집 모드 이미지 저장소 (IndexedDB)
js/app.js           화면 렌더링과 조작
data/scenario.js    시나리오 데이터 (캐릭터, 장면, 단서, 핸드아웃)
tests/coc.test.js   룰 엔진 테스트
```

## 테스트

```
node trpg-backup/room/tests/coc.test.js
```

## 이미지 교체

1. 플레이 화면에서 `편집 모드` → 슬롯을 누르거나 `에셋 관리`를 열어 이미지를 넣어
2. `완료`로 나와서 그대로 플레이
- 이미지는 자동으로 줄여서(배경 1920px, 스탠딩 1400px, 프로필 512px) 브라우저 IndexedDB에 저장돼. 스탠딩/프로필은 투명 배경이 유지돼
- 기기를 옮길 때는 `에셋 관리` → `이미지 내보내기`/`불러오기` (세이브 JSON과는 별개 파일)
- 주소(URL)를 끌어놓으면 가져오되, 서버가 막으면 주소만 연결돼서 원본이 사라지면 깨져
- 영구 배포본에 넣고 싶으면 `data/scenario.js`의 `bg`/`sprite`/`portrait`에 파일 경로를 직접 적어도 돼 (교체한 이미지가 우선)

## 시나리오 바꾸는 법

`data/scenario.js`만 수정하면 돼. 이미지/음원 경로는 비워도 되고, 비우면 그라데이션과 이니셜로 대체돼.
장면 `bg`에는 CSS 그라데이션이나 이미지 경로(`images/rooftop.jpg`)를 쓸 수 있어. BGM은 `SCENARIO.bgm`에 `{ 장면id: "music/x.mp3" }`로 연결해.
저장 데이터는 시나리오 `id`가 같을 때만 불러와져.

## 참고

- 브라우저 자동재생 정책 때문에 BGM은 첫 클릭 이후에 재생돼.
- 저장은 브라우저 localStorage, 교체한 이미지는 IndexedDB라 브라우저/기기가 바뀌면 JSON과 이미지 내보내기로 옮겨야 해. 브라우저 사이트 데이터를 지우면 둘 다 사라져.
- 이 폴더는 `trpg-backup` 사이트 안의 `/room/` 경로라서, 기존 사이트를 올리는 방법 그대로 올리면 같이 반영돼. 목록 페이지 상단에 링크가 있어.
